About My Notes

My Notes is a simple and user-friendly notes taking application built using HTML, CSS and JavaScript.

It allows users to create, edit, search and delete notes directly from their browser.

✨ Features

  • ➕ Create new notes
  • ✏️ Edit existing notes
  • 🗑️ Delete notes
  • 🔍 Search notes
  • 🌙 Dark mode
  • 💾 LocalStorage support
  • 📱 Responsive design

🛠️ Technologies Used

HTML5 CSS3 JavaScript LocalStorage

⚙️ How It Works

Notes are stored in your browser using JavaScript LocalStorage. This means your notes remain available even after refreshing or reopening the page on the same browser.

📚 Project Information

This project is designed as a beginner-friendly JavaScript project to demonstrate DOM manipulation, event handling, LocalStorage and responsive web design.
